# 知识库文档登记表

## 管理约定

- 分类：商品、物流、售后三类；跨类资料标记为“商品/物流/售后混合”。
- 命名：`【分类】主题_V主版本.次版本_YYYYMMDD`。
- 状态：`生效` 或 `停用`；只有生效文档允许进入客服检索。
- 更新：复制旧文档留档，上传新版本并完成召回测试；验证通过后启用新版本，再将旧版本停用。
- 追溯：记录文档来源、版本、状态和最近一次召回测试结果。
