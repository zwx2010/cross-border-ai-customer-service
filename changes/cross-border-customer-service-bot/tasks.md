## 任务

- [ ] **1.1 定义 Dify 会话变量和输入输出协议**：建立语言、意图、风险级别、失败次数、人工状态、会话摘要等字段；影响范围：Dify 工作流变量和 API 边界；结果：各分支使用统一字段；证明：执行变量初始化和分支传递测试。
- [ ] **1.2 搭建三语识别与业务意图路由**：配置英语/越南语/泰语识别，以及商品、订单物流、售后三类路由；影响范围：Dify 路由节点；结果：三语等价问题进入同一业务分支；证明：三语路由测试集。
- [ ] **1.3 配置知识检索与回答生成**：为商品、物流、售后内容建立检索和回答节点；结果：回答只引用有效知识或明确说明无法确定；证明：命中、未命中和来源展示测试。
- [ ] **2.1 实现人工接管风险判断**：配置恶劣语气、明确转人工、连续两次无法回答、退款/赔付/投诉规则；结果：命中任一条件即停止自动处理；证明：人工接管回归测试。
- [ ] **2.2 生成转人工会话摘要**：整理用户语言、意图、问题、已收集信息和触发原因；结果：人工接手时可直接了解上下文；证明：四类触发场景摘要字段检查。
- [ ] **3.1 建立知识库文档管理约定**：定义文档分类、版本号、生效状态和更新/停用流程；结果：文档状态可区分且可追溯；证明：版本生命周期测试。
- [ ] **3.2 增加知识库检索测试入口**：支持输入测试问题并展示命中文档、片段和版本；结果：管理员能验证新内容是否被正确检索；证明：检索测试报告。
- [ ] **4.1 编制三语综合验收集**：覆盖商品、订单物流、售后、知识库、未命中和四类人工接管条件；结果：每条样例有期望语言、意图、回答要点和转人工结果；证明：验收集审查记录。
- [ ] **4.2 执行准确率和边界回归**：在 Dify 预览环境运行固定验收集并记录结果；结果：常见问题准确率达到 90%，高风险条件无漏转；证明：验收结果表和失败样例清单。

## 实施备注（仅在必要时）

- 首期只验证 Dify 内部工作流，不连接外部电商平台或真实退款/赔付接口。
- 后续自动翻译专项优化、客服数据分析和外部渠道接入应作为独立变更评估。
