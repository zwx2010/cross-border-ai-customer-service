# Vue 3 跨境客服前端与协作服务

## Why

现有跨境电商客服机器人已在 Dify 内完成三语核心客服、知识库和人工接管验收，但目前缺少面向消费者和客服人员的可用界面，也缺少安全、可持久化的外部 API 接入层。直接让浏览器调用 Dify 会暴露 API Key，且无法统一保存会话、同步人工转接状态或向飞书协作渠道推送上下文。本变更将 Dify 能力包装为独立后端服务，并建设可配置主题的 Vue 3 双模式前端。

## What Changes

- 新增独立 Vue 3 前端项目，提供消费者聊天页和客服工作台。
- 新增独立 Node.js + TypeScript + Fastify 后端，代理 Dify API 并处理 SSE 流式响应。
- 使用 MySQL 持久化会话、消息、语言、摘要和人工转接状态。
- 接入飞书 Webhook 通知与飞书自建应用机器人双向协作。
- 通过配置文件和 CSS 变量提供品牌色、明暗、圆角、字体和布局密度定制。
- 提供 Docker Compose 本地部署方案和生产云部署方案说明。

## Scope

### In Scope

- 复用现有 Dify 工作流的三语对话、商品/物流/售后问答和人工转接输出。
- 前端发送消息、展示流式回复、恢复历史会话、展示来源与人工状态。
- 客服工作台查看会话、摘要、触发原因和接管状态。
- 消费者聊天页在机器人转人工后显示明确的等待/接管状态。
- 后端鉴权、请求校验、Dify API Key 管理、错误处理和幂等保存。
- 飞书转接通知、摘要推送和客服接管指令回传。
- MySQL 数据模型、迁移、健康检查和部署配置。

### Out of Scope

- 自动执行退款、赔付、订单修改或其他电商交易操作。
- Amazon、Shopee、Lazada、独立站等电商平台接入。
- 客服数据分析、报表和运营指标中心。
- 可视化主题编辑器和运行时主题管理后台。
- 修改或重新发布现有 Dify 工作流；Dify 仍由用户自行管理。

## Impact

- **新增区域**：独立前端项目、独立 Fastify 服务、MySQL 数据层、飞书适配层和部署配置。
- **兼容边界**：Dify API 适配器必须兼容现有 Workflow 应用的 `chat-messages` 接口、`conversation_id` 和流式事件。
- **安全边界**：浏览器不得接触 Dify API Key；飞书签名、令牌和数据库凭据仅由后端管理。
- **完成证明**：在本地 Docker Compose 和生产配置检查环境中完成三语流式对话、历史恢复、人工转接、飞书通知/接管和密钥不泄露验收。
