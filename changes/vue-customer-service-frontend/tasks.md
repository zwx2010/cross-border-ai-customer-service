## 任务

- [x] **1.1 建立独立项目边界**：创建前端和后端项目目录、版本约定、环境变量样例和共享 API 类型；影响范围：`frontend/`、`backend/`、项目文档；结果：两项目可独立安装、构建和启动；证明：前端构建、后端类型检查和配置校验。
- [x] **1.2 定义后端领域模型**：定义会话、消息、摘要、人工状态、转接事件和飞书事件去重字段；影响范围：`backend/src/domain`、MySQL migrations；结果：字段可支持恢复、幂等和状态回写；证明：迁移执行与模型测试。
- [x] **2.1 实现 Dify Adapter**：封装 `chat-messages`、`conversation_id`、用户标识、SSE 增量/结束/错误事件和超时；影响范围：`backend/src/integrations/dify`；结果：前端不接触 Dify 协议或密钥；证明：模拟 Dify 流式和错误测试。
- [x] **2.2 实现会话 API**：提供创建/列出/读取会话、发送消息、流式响应和重试接口；影响范围：`backend/src/modules/conversations`；结果：消息写入幂等且可恢复；证明：API 集成测试和并发/重复事件测试。
- [x] **3.1 建立共享前端状态与 API client**：统一会话、消息、流式状态、错误和人工状态映射；影响范围：`frontend/src`；结果：两种页面不重复实现协议逻辑；证明：状态单元测试。
- [x] **3.2 实现消费者聊天页**：提供三语消息输入、流式渲染、重试、历史恢复和转人工状态；影响范围：`frontend/src/pages/customer`；结果：消费者能完成核心对话；证明：浏览器验收场景。
- [x] **3.3 实现客服工作台**：提供会话列表、筛选、消息记录、摘要、知识来源和人工接管操作；影响范围：`frontend/src/pages/agent`；结果：客服能定位待接管会话并处理状态；证明：工作台验收场景。
- [x] **4.1 实现人工转接同步**：保存 Dify 转接结果、触发原因和摘要，并向 Webhook 推送通知；影响范围：`backend/src/modules/handoff`、`backend/src/integrations/feishu`；结果：转接不丢失且可重试；证明：恶劣语气、明确转人工、连续失败和高风险售后测试。
- [x] **4.2 实现飞书自建应用回写**：完成验签、事件去重、客服指令解析、权限判断和会话状态更新；影响范围：`backend/src/integrations/feishu`；结果：有效指令可接管，无效/重复指令不改变状态；证明：签名、权限、重放和回写测试。
- [x] **5.1 实现主题令牌与响应式布局**：定义主题 schema、默认值、非法值回退和桌面/移动断点；影响范围：`frontend/src/theme`、页面样式；结果：两种模式共享主题且不阻断聊天；证明：主题配置和响应式浏览器测试。
- [x] **5.2 编排本地与生产部署**：提供 Compose、数据库迁移、健康检查、反向代理/CORS、环境变量和云部署说明；影响范围：`docker-compose.yml`、部署文档和 CI 配置；结果：本地可启动，生产配置可检查；证明：启动、缺密钥、数据库/Dify/飞书不可用测试。
- [x] **6.1 执行集成验收**：覆盖三语、两种页面、流式、历史、知识来源、人工转接、飞书和安全边界；影响范围：验收测试集与报告；结果：每条场景有结果和证据；证明：验收报告与构建产物扫描。

## 依赖与边界

- 前端实现依赖后端 API 契约，不应绕过后端直连 Dify。
- 飞书双向接入依赖用户提供自建应用凭据、事件订阅权限和 Webhook 配置；未提供时只能完成模拟适配器验收，不能宣称真实联调通过。
- 生产云部署依赖用户选择云厂商、域名、TLS 和数据库托管方式；本变更先提供通用部署边界，不替用户创建外部资源。
